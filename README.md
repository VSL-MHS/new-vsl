# VSL Marketing Dashboard

React and Vite marketing dashboard for My Health School. The application is in `marketing-dashboard/`.

## Run locally

```sh
cd marketing-dashboard
npm ci
npm run dev
```

## Build

```sh
cd marketing-dashboard
npm run build
npm run preview
```

## Deploy on Vercel

- Framework: Vite
- Root directory: `marketing-dashboard`
- Install command: `npm ci`
- Build command: `npm run build`
- Output directory: `dist`

The dashboard currently uses demo data and browser local storage. No backend or environment variables are required.
